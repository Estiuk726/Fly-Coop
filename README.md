# C172 Flight Sheet

Fill in a flight and download the printable FLY-COOP VFR navlog and C172 M&B load sheet as a 2-page A4 PDF.

- Front: VFR navlog (fuel table filled) and M&B load sheet with CG chart
- Back: briefing (aircraft, ASI, flaps, NOTAMs, METAR/TAF LHBP, exercise)
- Trip fuel for M&B: 5 US gal/h local, 4.5 US gal/h cross country, 6.71 lbs/US gal
- Print double-sided, flip on short edge

Everything runs in the browser. Nothing is sent anywhere.
